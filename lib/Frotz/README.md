# Frotz for the Freenove terminal

The Frotz core comes from [upstream Frotz](https://github.com/DavidGriffith/frotz/tree/fe66e2ef738354f5e2fe37c7c01b1781ef659acd/src/common), revision `fe66e2ef738354f5e2fe37c7c01b1781ef659acd`. See `COPYING` and the source notices for the GNU GPL v2 or later terms. The firmware integrates this core with the project's terminal and microSD storage. Distributing the combined firmware requires complying with the applicable GPL terms, including providing corresponding source.

This port pages read-only story data from microSD. It uses the Z-code executable in a Blorb container and presents the story through a text interface.
